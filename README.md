# ThsLink

同花顺快捷下单与 HTTP 接口下单工具，支持桌面按钮、热键快捷下单，以及通过 HTTP 接口买入、卖出、撤单和查询账户数据。

支持本机、局域网及服务器远程 HTTP 调用：同花顺和 ThsLink 可运行在同一台 Windows 服务器上，你的电脑或另一台服务器通过 VPN 或 HTTPS 入口发送请求，无需处于同一局域网。

Windows 绿色便携版，无需安装。提供 **ThsLink 桌面版** 和 **ThsLink-Cli-纯接口版**；只需 HTTP 接口时选择纯接口版，无图形渲染依赖。

**当前版本：v0.3.7。仅供个人非商业学习与研究，禁止用于任何商业行为。**

## 交易端兼容与股票跟随

固定兼容路径覆盖普通版 `2026.07.02.0`、`2026.09.15.0` 和远航版 `2026.05.06.0`，并支持通过严格校验的 `2026.10.20.0` 及官方独立下单 `2023.03.30.0`。未知构建须通过完整自动发现与严格验证；不能以版本号相近推定兼容。官方独立下单版已验证账户读取、普通持仓、委托、成交、资金查询及 DLL 安全重载；实际买卖、撤单、账户切换和信用业务尚未在该版现场验收。

当前版本保留查询无更新状态处理：同花顺没有提供新的查询结果时，不会误报为 HTTP 502，也不会把缓存冒充本次新结果。精确匹配的 2026.10.20.0，以及通过缓存校验的官方独立下单 2023.03.30.0，普通委托、成交可返回显式标记的同账户原生缓存，仍保留无更新与时效、完整性待确认状态；缓存读取不依赖详细诊断开关。未取得缓存时继续显示本次无更新。交易端自动识别和严格验证继续有效；地址变化可以在已验证契约范围内自动发现，函数逻辑、布局或接口变化仍可能需要适配，不能以版本号变化大小判断兼容。

桌面股票跟随支持普通版与远航版。远航版使用随包 `quote-helper/` 只读辅助组件，需要 .NET Framework 4.5 或更高版本。连接状态与设置中可查看版本、权限和不兼容原因。

## 信用业务（v0.3.3）

信用交易请在同花顺中只登录一个账户，并使用“当前账户”。快捷按钮、批量编辑和 HTTP 请求生成器可选择交易业务；普通交易保持默认，不用添加参数。

HTTP 使用 `xytype`：1 担保品买入，2 担保品卖出，3 融资买入，4 融券卖出，5 买券还券，6 卖券还款。例如融资买入：

```json
{"side":"buy","code":"000001","price":"zxjg","amount":100,"xytype":3,"notip":true}
```

省略 `account` 或填写 `"current"`。业务编号错误或方向不匹配时拒绝发送，不会自动改为普通交易。信用全撤和撤当前票需明确选择“信用撤单（全部业务）”，HTTP 用 `credit: true`，不要与 `xytype` 混用。信用账户读取和四类查询可手动选择普通或信用模式。用户已在当前环境验收信用撤单；其他券商、交易端和业务仍须分别核对。详见 [HTTP 使用说明](docs/HTTP.md#信用交易v033)。请整体使用同一构建的程序包。

## 下载与启动

1. 下载 Release 中的 **`thslink-windows.zip`**，解压到有写入权限的目录。GitHub 自动生成的 Source code 压缩包不是程序包。
2. 先启动同花顺并登录交易账户，再双击 `thslink.exe`。主程序、`thslink_bridge.dll` 和 `thslink-load.exe` 须放在同一目录。
3. 运行环境为 Windows 10/11 x64，支持上述同花顺交易端版本；不兼容时会显示连接原因。
4. 打开主窗口“接口”开关。只用 HTTP 时，可以关闭“手动交易”，暂停自动读票和交易热键。

Release 另附 `ths-trading-2023.03.30.0.zip`（同花顺独立交易端），已清除原包内的历史账号标识。需要独立交易端时可单独下载、解压并运行其中的 `xiadan.exe`。它与 ThsLink 程序包分别下载；先登录交易端，再启动 ThsLink。已经使用受支持交易端的用户无需更换。

虚拟机或远程桌面遇到窗口黑屏时，退出 ThsLink 后双击包内 `兼容运行.bat`，使用带系统标题栏的兼容窗口。普通双击 EXE 仍使用无边框窗口。兼容模式不保证解决所有显卡或虚拟机渲染问题。

配置保存在 `%APPDATA%/thslink/ui-settings.json`。接口开关会保存，下次启动恢复；升级和移动程序目录不会清空该 Windows 用户的配置。

**从旧版升级，请先退出 ThsLink 和同花顺交易端，整体替换便携包，再重新启动。**不要只换 EXE 或把新旧 DLL 混用。

运行中 DLL 断线会自动重连，连续 3 次连接失败后尝试安全卸载、重新加载和验证；完整重载至少间隔 30 秒，没有重试次数上限。未确认结果先保存，原生任务或回调仍在执行时暂不卸载。DLL 完全无响应时，现有通道无法保证恢复。恢复不会退出或重启同花顺，也不会重发交易。

退出时先尝试安全卸载 DLL；失败后可重试、继续运行或强制退出 ThsLink。强制退出只结束本程序，交易端保持运行，DLL 可能仍驻留；不会自动关闭同花顺。

### 纯接口版

下载 **`ThsLink-Cli-windows.zip`**，解压后先登录同花顺交易端，再双击 **`启动 ThsLink-Cli(点这个).bat`**。也可直接启动 `ThsLink-Cli.exe`。菜单 1 查看状态、2 接口用法、3 连接交易端、4 接口设置、5 核对不确定结果、0 退出。菜单 4 可设置地址、端口和密钥，保存后退出重启生效。

纯接口版与桌面版只能运行其中一个。虚拟机或服务器使用时，请保持 Windows 用户已登录、同花顺交易端正在运行。完整说明见 [纯接口版说明](docs/CLI.md)。

## HTTP 快速上手

默认地址：`http://127.0.0.1:8421`。请求体为 JSON，默认启用随机密码，请携带 `X-API-Key`（仅手动关闭验证后可省略）。所有 HTTP 交易请求必须填写 `notip: true`；批量中每笔都要填写，漏填或 false 会在发送前返回 HTTP 400。账户数据查询不需要此参数。

先查持仓，发送到 `POST /query`：

```json
{"kind":"holdings","account":"current","mode":"ordinary","wait_ms":2000}
```

`kind` 可改为 `orders`（当日委托）、`deals`（当日成交）、`funds`（资金）。返回 `pending` 时，使用原 `query_id` 请求 `GET /queries/编号`，不要重新发起同一查询。

买入 100 股，发送到 `POST /order`（会实际提交买入委托）：

```json
{"side":"buy","code":"000009","price":"mrxjg","amount":100,"notip":true}
```

卖出将 `side` 改为 `sell`、`price` 改为 `mcxjg`。普通撤单不填价格和数量，例如普通模式全撤全部已登录账户：

```json
{"side":"cancel","code":"all","account":"all","notip":true}
```

`code=all` 选择撤单范围，`account=all` 选择账户范围；两个字段作用不同。信用用户应明确填写 `"credit":true`，首次使用以当前单一信用账户为准。

`batch_id` 自 v0.2.8 起为 GUID 字符串，须原样保存使用，不能转为数字。批次 `complete` 仅表示成员完整，仍需逐笔检查结果。回执查询的 404/503/502 与 `query_status` 表示查询问题，不证明原订单失败，不能据此重下。

### 多账户与比例

| 填法 | 含义 |
|---|---|
| 省略 account | 交易使用同花顺当前账户；查询默认 current |
| `"account":"ACCOUNT_ID"` | 将占位符替换为实际已登录账户号 |
| `"account":"all"` | 当前交易端全部已登录账户，不自动登录其他账户 |
| `"cw":"1/10"` | 买入按可用资金 10%；卖出按可卖数量 10% |
| `"zzc":0.1` | 本次买卖金额占账户总资产 10% |
| `"zcw":0.25` | 交易后这只股票还剩多少仓位：目标为总资产的 25% |

`amount`、`m`、`cw`、`zzc`、`zcw` 五选一。比例支持小数和字符串分数，例如 `0.1` 或 `"1/10"`。指定账户无需先切换同花顺当前账户。

### 批量请求

发送到 `POST /orders/batch`，每批 1～20 笔，每笔单独设置参数和账户：

```json
{"orders":[
  {"side":"buy","code":"000009","price":"mrxjg","amount":100,"notip":true},
  {"side":"buy","code":"600000","price":"mrxjg","cw":"1/10","notip":true}
]}
```

批量不是原子事务：一笔失败不会撤回其他已提交的委托。保存 `batch_id`，再用 `GET /batches/编号` 查看逐笔结果。

### 接口速查

| 方法与路径 | 用途 |
|---|---|
| `POST /order` | 单笔买入、卖出、撤单 |
| `POST /orders/batch` | 批量提交 |
| `GET /orders/:id` | 用 request_id 查询单笔回执 |
| `GET /batches/:id` | 用 batch_id 查询整批及逐笔状态 |
| `POST /query` | JSON 主动查询：kind、account、mode、wait_ms |
| `GET /query/:kind` | GET 方式主动查询，与 POST 返回一致 |
| `GET /queries/:id` | 用 query_id 读取同一次查询结果 |
| `GET /health` | 检查连接状态 |
| `GET /who` | 获取账户信息 |
| `GET /last` | 最新回执，仅供诊断，不代替按编号查询 |

查询结果在 `accounts → tables → rows` 中；检查 `status`、`complete` 及账户错误，不能仅看 HTTP 200。只有收到完整空表才表示没有记录；缺失字段不能当作数值 0。分页和容量边界见[完整说明](docs/HTTP.md)。

## Python 连续调用

服务端默认支持 HTTP Keep-Alive。你的 Python 程序启动时创建一次 `requests.Session()`，下单、查询和轮询都使用同一个 Session，程序退出时再关闭。软件生成的 Python 代码与[示例文件](examples/http_demo.py)均采用这个方式。

不要每次调用都重新创建客户端；仅添加 `Connection: keep-alive` 请求头不能代替复用。网络中断后后续调用可以重新建连接，**交易 POST 超时不能盲目重发**：上一笔可能已提交，应先查回执或当日委托。

## 局域网与远程调用

同花顺和 ThsLink 运行在同一台 Windows 电脑上，其他电脑通过 HTTP 调用，无需安装同花顺或 ThsLink。

1. 在设置中允许局域网访问，将监听地址设为 `0.0.0.0`，配置端口与 API 密钥，修改后重启接口。
2. 调用端使用服务端实际 IP，例如 `http://192.168.1.100:8421`；Windows 防火墙允许所需来源访问。
3. `127.0.0.1` 只访问调用端本机，`0.0.0.0` 仅用于监听，不能当作远程调用地址。

通过公网调用时，可使用 VPN 组网后访问 VPN 地址，或自行配置带身份认证的 HTTPS 入口。程序本身提供 HTTP，未内置 HTTPS 证书或 VPN。接口用法保持一致。

## 更新与数据保存

更新由用户手动操作，启动时和后台不会自动检查。软件内检查需要先在设置中的 HTTP 接口区域填写可信的 HTTPS 发布信息地址；留空时请打开 [发布页面](https://github.com/electkismet/thslink/releases/latest) 手动下载完整包。

请求与回执证据保存到 `%LOCALAPPDATA%/ThsLink/request-history.jsonl`，重启后恢复待核对记录。该文件包含交易命令、账户选择参数和回执，请按交易记录保管。调用程序仍应保存完整业务日志、请求编号与结果。账户配置、密钥、技术日志和源码不随便携包分发。

当前版本延续异步下单与回执处理：正常等待某笔回执时可以继续提交后续委托，结果按原请求编号更新；查询无更新时返回明确的 `unchanged` 状态。超时不会取消委托；遇到不确定结果请核对原请求和券商记录，程序不会自动重发。详细字段和异常处理见 [HTTP 使用说明](docs/HTTP.md)。

## 兼容范围与安全

已适配构建和未知构建均会核对接口契约；只有唯一候选且验证完整时才启用。适配器仅处理已审阅的地址与结构变化，其他交易端更新仍可能需要修改程序。信用交易请只登录一个账户，使用当前账户；用户已确认当前环境信用撤单可用，其他场景不由此保证。

HTTP 默认启用随机 API 密钥。桌面主窗口可关闭或开启密钥验证，设置页可查看、复制和更换密钥。在线调试页默认读取本机密码，支持填写远程密码、预览和复制请求头；生成代码默认用占位符，可选择包含密钥。密码不放在 JSON 或网址中。

ThsLink 提供普通 HTTP。公网或不可信网络调用时请使用 VPN 或受信任的 HTTPS 入口，不要直接暴露未加密的 HTTP 服务。
